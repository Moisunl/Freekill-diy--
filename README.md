# Freekill-diy-贾诩
自制，爱好制作，随便取用，标注出处。

关于这个想法，是我从接触AI就有的，AI是一个工具，用对的方法，造就想象的成果。

我从25年9月构思后，直到26年2月份，我从没接触过代码的白丁，照着教程，一点一点调试出它。这个过程无疑是漫长而艰难的，但是我仍然为此感到愉悦。

有些天马行空的创意，只有到落实在游戏中才知道有多少不规范，多少天方夜谭。这是我第一次有了跨对立身份思考同一个问题的意识，这份觉悟来之不易，更难得的是，我将为这种来之不易的灵感和体会而孜孜不倦，持之以恒。
